Ecliptica Token Tracker
=

VRChatのワールド「ECLIPTICA」のログをリアルタイムで解析し、
トークンの所持数・最大数を画面上にオーバーレイ表示するサポートツールです。

【主な機能】
- トークン数のリアルタイムオーバーレイ表示
- ログ変更履歴の表示
- タスクトレイ（画面右下）常駐 ＆ 設定機能
  - レシート表示の ON / OFF 切替
  - ログ表示件数の変更（1〜20件）

------------------------------------------------------------------------
■ 使い方
------------------------------------------------------------------------
1. ダウンロードした ZIP ファイルを解凍します。
2. 「EclipticaTokenTracker.exe」を実行します。
3. 画面右下にオーバーレイが表示されます。
4. 設定を変更したい場合は、タスクトレイ（通知領域）にあるアイコンを
   右クリックして「設定」を開いてください（ダブルクリックでも開けます）。

------------------------------------------------------------------------
■ 注意事項・動作環境
------------------------------------------------------------------------
・OS: Windows 10 / 11 (64-bit)
・本ツールはVRChatの出力ログ（output_log_*.txt）を読み取って動作します。
・VRChat起動後に本ツールを起動しても、直近のログを読み込んで動作します。
・本ツールは非公式のサードパーティ製ツールです。ワールド公式とは関係ありません。
